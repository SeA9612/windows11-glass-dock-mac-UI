# Release Note0.1.0 ver

대상: GlassDock 초기 실행본 및 개발 전 합의. 관련 기록: 2026-11-03~05. 정리일: 2026-11-09.

과거 문서의 `0.1`을 `0.1.0` 형식으로 정리했습니다. 아래 HTML 수정본 번호는 제품 버전이 아닙니다. 이 저장소는 당시 실행본을 별도로 배포하지 않으며, 현재 실행용 ZIP은 0.2.1입니다.

## 개발 전 확정한 방향

- Windows의 키보드 입력·단축키, 탐색기·브라우저와 각 앱의 내부 UI를 유지하고, 독·창 선택·미리보기의 외형과 모션을 개발하기로 했습니다.
- 독은 한 모니터에 표시하고 사용자가 다른 모니터로 옮길 수 있게 하며, 상·하·좌·우 가장자리에 붙이는 방향으로 정했습니다.
- Windows 기본 작업 표시줄과 트레이를 유지하기로 했습니다. 모든 앱의 시스템 애니메이션을 macOS와 동일하게 교체한 것은 아닙니다.

이 단계의 창·작업공간·AI는 체험 화면입니다. 실제 Windows 앱 제어와 로그인·기존 대화 읽기·전송이 구현됐다는 의미가 아닙니다. 특히 AI 체험용 응답은 초기 실험 뒤 제거했으며 실제 연결 성공으로 표시하지 않았습니다.

## 초기 Windows 실행본에 도입한 기능

- C# WPF 독과 실제 창 감지, 실행 경로 기준 앱 그룹화, 실행 표시·창 개수.
- 고정 앱, 드래그 순서 저장, 선택 모니터·가장자리·자동 숨김 설정.
- 현재 가상 데스크톱의 창을 대상으로 선택·최소화·복원하는 클릭 정책.
- DWM 기반 창 미리보기, 전체 창 목록, Windows 작업 보기 호출.
- 트레이 종료와 로컬 설정 저장, .NET 런타임 포함 Windows x64 실행본.

초기 전체 창 보기는 목록과 큰 썸네일 중심의 첫 구현이었습니다. 승인된 카드형 전체 화면 선택 UI로의 수정은 0.2.1에 기록합니다.

## 당시 확인과 남은 사항

기존 0.2 문서는 사용자가 0.1의 Windows 실행을 확인했다고 기록합니다. 초기 핵심 클릭 정책 12개와 Release 빌드·win-x64 게시 성공 기록도 있습니다. 당시 클라우드 검증은 실제 Windows의 창 조작·DWM·모니터·배율·성능 검증을 대신하지 않습니다.

기존 AI 대화 연동, 모든 트레이 앱 식별, 혼합 DPI·다중 모니터와 전역 창 애니메이션의 동일한 동작은 완료로 기록하지 않습니다. AI 및 독 외형의 최종 상태는 이후 버전 노트를 우선합니다.

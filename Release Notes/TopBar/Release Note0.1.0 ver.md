# Release Note0.1.0 ver — GlassDock TopBar

대상: 별도 상단 바 프로그램. 개발·로컬 배포 정리: 2026-11-06. 이 노트 작성: 2026-11-09, 한국 시간.

로컬 `TopBar.csproj`의 제품 버전은 **0.1.0**입니다. 독과 다른 프로그램이므로 같은 번호의 독 노트와 구분합니다. **현재 GitHub에 올린 독 ZIP·소스에는 상단 바가 포함되어 있지 않습니다.** 아래 내용은 프로젝트 대화와 로컬 배포 기록을 정리한 개발 이력입니다.

## 최종 적용 상태

- 높이 28 DIP 상단 바와 선택 모니터 위쪽 작업영역 예약.
- 실제 전경 앱 이름, 앱·창 메뉴, 키보드 언어, 네트워크, 음량·음소거, 배터리, 날짜·시간과 달력.
- 해당 모니터에 보이는 최대화·전체 화면 창이 있으면 바 배경 불투명도 100%, 그 외 일반 창·최소화·바탕화면 상태는 배경·경계선 없이 0%.
- 메뉴·하위 메뉴·상태 패널·트레이는 독과 같은 투명 유리 재질. 글자·아이콘은 유지하고 분홍색 선택 효과는 사용하지 않음.

## 수정 이력

### 배경과 창 상태 감지

처음 불투명 배경을 완전히 투명하게 만든 뒤, 가독성 요청으로 30% 불투명도를 적용했습니다. 이후 약 0.2초 간격으로 창 상태를 감지해 최대화 70%·일반 창 30%·바탕화면 0%로 전환했습니다.

후속 요청에 따라 최대화·전체 화면은 100%로 올리고, 일반 창에서 띠처럼 남던 30%도 제거했습니다. **현재 기준은 최대화·전체 화면 100%, 그 외 0%**이며 중간 수치로 되돌리지 않습니다. 최소화 창과 다른 공간의 숨겨진 창 등은 상태 판단에서 제외합니다.

### Windows 시스템 메뉴

Windows 버튼에 PC 정보, 시스템 설정, Microsoft Store, 최근 사용 항목, 작업 관리자, 절전·재시동·종료·잠금·로그아웃을 추가했습니다. 최근 항목 하위 메뉴를 구현하고, 재시동·종료·로그아웃은 확인 창을 거치게 했습니다. 제안 단계의 분홍색 선택 효과는 사용자 정정에 따라 회색 계열로 바꿨습니다.

### 실제 숨겨진 트레이 연결

장식·비활성 상태였던 화살표를 실제 Explorer 숨겨진 트레이 팝업과 연결했습니다. 팝업은 상단 화살표 바로 아래에서 열리며, 원래 아이콘의 클릭·우클릭·툴팁·콜백은 Windows가 처리합니다.

작업 표시줄이 숨겨져 버튼을 찾지 못하던 경우를 위해 이미 생성된 팝업을 직접 여는 경로를 추가했습니다. 바깥 클릭·Esc·화살표 재클릭으로 닫고, 종료·닫기 시 원래 위치와 스타일을 복원합니다. 비정상 종료 복구 감시와 시작 시 복구도 추가했습니다. 작업 표시줄에 고정된 아이콘을 숨겨진 트레이로 강제로 옮기지는 않습니다.

### 알림 위치

Windows 기본 알림 호스트가 나타나면 상단 바 오른쪽 아래에 배너를 배치하도록 했습니다. 알림 내용·발신자를 읽거나 저장하지 않고 창 위치를 조정합니다.

개발 PC에서는 카카오톡 자체 알림 설정도 우상단으로 변경했습니다. 이는 앱별 로컬 설정이며 배포 파일로 자동 이전되지 않습니다. 다른 PC에서는 카카오톡 알림 위치를 따로 설정해야 합니다.

### 메뉴·트레이 유리 재질

독의 배경을 어두운 패널로 해석했던 부분을 사용자 정정에 따라 투명 유리로 수정했습니다. 독의 유리 테마·반사·배경 합성 구현을 팝업에 맞춰 재사용하고 Windows Composition 배경 흐림, 옅은 색조, 밝은 테두리·안쪽 반사·그림자를 적용했습니다.

밝고 어두운 배경에 따라 글자 색을 조정합니다. 메뉴·하위 메뉴·소리·네트워크·언어 패널 및 트레이에 적용하며, 트레이는 Explorer의 실제 입력 창을 유지한 상태에서 유리 표면과 아이콘 그림을 표시합니다.

## 당시 검증과 로컬 배포

- 배경 단계에서 빌드와 29개 검사, 트레이 연결 단계에서 34개 기본 검사 및 실제 열기·닫기·위치 복원을 확인한 기록이 있습니다.
- 최종 상태·배치·Win32 ABI 검사 42개, 밝고 어두운 배경의 메뉴·하위 메뉴 표시, 실제 트레이 클릭 영역·외부 포커스 닫기·재열기·스타일 복원·복구 경로를 확인했습니다.
- Windows 테스트 알림 위치는 확인했으나 카카오톡 실제 메시지 수신 검사는 하지 않았습니다.
- 로컬 실행본·소스 통합 ZIP을 만들고 압축 해제본의 소스 빌드와 42개 검사를 확인했습니다. 런타임 포함 실행파일 폴더 전체를 옮기는 방식입니다.
- 개인 설정·오류 로그·카카오톡 데이터·빌드 캐시는 로컬 소스 배포에서 제외했습니다. 자동 시작은 등록하지 않습니다.

위 항목은 당시 기록이며 이번 릴리즈 노트 작성에서 재검증하지 않았습니다.

## 남은 제한

Windows 트레이·알림 내부 창 클래스에 의존하는 부분은 Windows 업데이트 후 호환성 확인이 필요합니다. 다른 앱의 자체 알림 위치는 앱마다 다르며, 방해 금지나 알림 비활성화를 강제로 해제하지 않습니다. 독점 전체 화면에서는 OS 앱바 규칙에 따라 뒤로 갈 수 있습니다.

키보드 언어 표시는 IME의 가/A 상태 표시와 다릅니다. 각 앱의 파일·편집 메뉴를 상단 바로 옮기는 범용 연동은 구현하지 않았습니다.

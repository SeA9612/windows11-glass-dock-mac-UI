## 버전과 날짜 기준

- **2026-11-11 추가:** 지니 최소화 효과를 새 기능으로 배포하면서 제품 버전을 **0.3.0**으로 올렸습니다. 이 버전은 실제로 빌드·실행 테스트 후 배포했으며, 아래의 0.2.1 기준 설명은 당시 기록으로 그대로 둡니다.
- 현재 업로드된 독 소스의 제품 버전은 **0.2.1**입니다. 같은 버전 안에서 누적 수정된 작업은 해당 노트의 순서별 항목으로 기록했습니다. 확인되지 않은 0.2.2 이후 버전을 만들지 않았습니다.
- 과거 문서의 `0.1`, `0.2`는 파일 이름에서 각각 `0.1.0`, `0.2.0`으로 표기했습니다. 옛 실행 파일의 전체 제품 버전이나 Git 태그를 확인했다는 의미는 아닙니다.
- 상단 바는 로컬 소스 기준 **0.1.0**이며 독과 별도 프로그램입니다. 상단 바의 개발 이력도 함께 기록하지만, 현재 GitHub 실행용 ZIP과 소스에는 상단 바가 포함되어 있지 않습니다.
- 작업일과 정리일을 구분했습니다. 이 문서는 과거 기록을 정리한 것이며, 새 프로그램 배포나 과거 날짜의 GitHub Release 생성은 아닙니다.
- 검증 수와 결과는 **당시 대화·문서에 남은 기록**입니다. 이번 문서 작성 과정에서 프로그램 테스트를 재실행하지 않았으며, 서로 다른 단계의 검사 수를 합산해 최종 통과 수로 표시하지 않았습니다.

# Release Note0.2.0 ver

대상: GlassDock 0.2 화면 수정 단계. 관련 기록: 2026-11-05. 정리일: 2026-11-09.

과거 문서의 `0.2`를 `0.2.0` 형식으로 정리했습니다. 현재 실행용 ZIP의 최종 상태는 [0.2.1 노트](Release%20Note0.2.1%20ver.md)를 기준으로 합니다.

## 수정·적용 사항

- 실행 화면의 기본 WPF 입력 컨트롤을 승인 예시의 둥근 버튼·입력창·간격으로 정리했습니다.
- AI 영역 상단에 서비스 상태와 접기 버튼을 배치하고, 서비스 선택·앱 추가 및 대화 선택·새 대화 항목을 두 줄로 정렬했습니다.
- AI 내용 영역 498×442 DIP, 전체 폭 538 DIP를 기준으로 구성하고 입력창을 아래에 고정했습니다.
- 당시 아이콘을 46 DIP 그라데이션 타일·벡터 심벌·실행 점으로 정리했습니다. 실제 실행 앱이 아닌 예시 앱을 고정 표시하지 않았습니다.
- 일반 독 배경은 채우지 않고 AI 패널을 열 때만 흰 배경을 표시하도록 했습니다.
- AI 패널의 높이를 매 프레임 바꾸는 대신 페이드와 작은 확대·축소를 사용하고, 갱신 시 제어 버튼을 반복 생성하던 부분을 줄였습니다.
- 기존 고정 앱·순서·설정과 서비스별 로컬 초안을 보존했습니다.

## AI 상태 표시

서비스 이름 등록과 실제 로그인을 구분했습니다. 기존 대화 선택·새 대화 생성·전송은 미연결 상태에서 비활성화하고, 초안은 로컬에 저장되며 전송되지 않는다고 표시했습니다. 실제 API 전송이나 가짜 AI 응답은 추가하지 않았습니다.

## 당시 검증

Release XAML/C# 빌드와 기존 클릭 정책 테스트가 통과한 기록이 있습니다. 업데이트 도구는 전체 파일 복원, 작은 배포본 복사, 기준 파일 불일치 거부, 결과 체크섬 오류 거부와 원본 보존을 Linux PowerShell에서 확인했습니다.

당시 Windows 실제 렌더링·모션·배율별 화면 비교와 Windows PowerShell 5.1 업데이트 실행은 미검증이었습니다. 승인 예시와 픽셀 단위 동일함을 확인한 단계는 아닙니다.

## 이후 변경된 사항

이 버전의 AI 패널·46 DIP 장식 타일·배경 규칙은 역사 기록입니다. 후속 0.2.1 누적 수정에서는 전용 AI 버튼을 제거하고, 32 DIP 실제 Shell 앱 아이콘과 유리 독·실시간 미리보기를 적용했습니다. 옛 화면 구성을 현재 기능으로 안내하지 않습니다.

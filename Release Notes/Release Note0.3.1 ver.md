# Release Note0.3.1 ver

대상: GitHub에 업로드된 GlassDock 독 실행본과 소스. 개발·검증·이 노트 작성: 2026-11-18, 한국 시간.

제품 버전은 `source/src/Dock/Dock.csproj`의 **0.3.1**입니다. 0.3.0의 기능(지니 최소화 효과 포함)은 그대로 유지하며, 이번 버전은 Windows 가상 데스크톱 전환 문제를 수정했습니다.

## 현재 적용 상태

- Windows 데스크톱을 전환해도(Ctrl+Win+←/→, 작업 보기에서 다른 데스크톱 선택) 독이 사라지지 않고 모든 데스크톱에 표시됩니다.
- 독의 앱 아이콘·실행 점·창 목록·지니 효과는 지금 보고 있는 데스크톱의 창을 기준으로 동작합니다(0.2.1부터의 현재 작업공간 기준 그대로).
- 같은 문제를 겪던 상단 바도 함께 수정해 [상단 바 0.1.5](https://github.com/SeA9612/windows11-top-bar-mac-UI)로 배포했습니다.

## 1. 데스크톱 전환 시 독이 사라지던 문제

- **증상:** 데스크톱 1에서 실행한 독이 데스크톱 2로 넘어가면 보이지 않았습니다.
- **원인:** Windows가 독 창(유리 배경 창 포함)을 데스크톱 1에 속한 일반 앱 창으로 보고, 다른 데스크톱에서는 숨김(DWM `cloaked` 값 2) 처리했습니다. 유리 배경 창은 이미 도구 창 스타일이었지만 함께 숨겨져, 창 스타일 변경만으로는 해결되지 않았습니다.
- **수정 1 — 모든 데스크톱에 고정:** 작업 보기에서 창을 우클릭해 고르는 "모든 데스크톱에 이 창 표시"와 같은 방식으로 독 창을 고정합니다. 전환 애니메이션 중에도 사라지지 않습니다. Windows가 공식 문서로 제공하지 않는 셸 기능이라, 2초마다 고정 상태를 확인해 새로 생긴 창이나 탐색기 재시작 후 풀린 고정을 다시 적용합니다.
- **수정 2 — 예비 방식:** 고정 기능을 쓸 수 없는 Windows 버전에서는, 데스크톱 전환으로 독 창이 숨겨지는 순간 공식 API(`IVirtualDesktopManager.MoveWindowToDesktop`)로 현재 데스크톱에 옮깁니다. 이 경우 전환할 때 잠깐 깜빡일 수 있습니다.
- 추가 파일: [AllDesktops.cs](../windows11%20glass%20dock%20mac%20UI/source/src/Dock/AllDesktops.cs). 동작 기록은 `%LOCALAPPDATA%\GlassDock\startup.log`에 남습니다.

## 당시 검증 기록

| 단계 | 기록된 결과 | 범위·제한 |
|---|---|---|
| 원인 확인 | 수정 전, 다음 데스크톱에서 독·유리 배경·상단 바 창 모두 `cloaked=2` | 실제 데스크톱 전환(Ctrl+Win+→)으로 확인 |
| 고정 방식 | 다음 데스크톱에서도 독·유리 배경 `cloaked=0`, 돌아와도 정상 | 이 PC의 Windows 11 25H2(빌드 26200)에서 고정 기능 동작 |
| 예비 방식 | 고정을 끈 시험 모드에서도 전환 후 독이 현재 데스크톱으로 이동해 표시 | 시험 모드는 환경 변수 `GLASSDOCK_NO_DESKTOP_PIN=1`로만 켜짐 |
| 데스크톱 2에서 지니 효과 | `_` 버튼 최소화 → 독 클릭 복원 → 독 아이콘 최소화 통과 | Windows 문자표 창으로 실행 |
| 단위 테스트 | 클릭 정책 15개, 배치·비율 30개, 앱·도구 순서 18개, 지니 곡선 17개 통과 | 기존 테스트 그대로 |
| 배포본 | Release / win-x64 / self-contained 게시, 게시한 실행본으로 전환 테스트 재확인, ZIP 내부 EXE와 원본 SHA-256 일치 | 다른 PC에서의 실행은 확인하지 않음 |

## 보류·지원 한계

- 고정 방식은 공식 문서가 없는 Windows 셸 기능이라, 다른 Windows 버전에서는 예비 방식(전환 때 잠깐 깜빡임)으로 동작할 수 있습니다. 실제 다른 Windows 버전에서는 확인하지 않았습니다.
- 호버 미리보기·전체 창 보기·지니 효과 화면은 열 때마다 새로 만들어지므로 지금 데스크톱에 나타납니다. 이런 화면을 연 채로 데스크톱을 전환하는 경우는 따로 검증하지 않았습니다.
- 보조 모니터와 여러 데스크톱의 조합은 확인하지 않았습니다.

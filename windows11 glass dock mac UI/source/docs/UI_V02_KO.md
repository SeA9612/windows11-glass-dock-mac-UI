## 독 표면 스타일

독 배경을 완전 투명 대신 푸른 기가 도는 반투명 유리 그라데이션으로 표시한다. 얇은 밝은 테두리, 상단 반사광, 부드러운 외부 그림자를 추가해 배경 위에서 독 형태가 분명히 보이도록 했다.
## 2026-11-05 AI 아이콘 변경

AI 패널 대신 바로가기 런처를 사용한다. 아이콘 클릭은 선택한 ChatGPT/Claude 앱을 Windows 시작 메뉴 등록 정보로 실행하거나 사용자 지정 실행 파일을 연다. 앱을 찾지 못하면 웹으로 대신 열지 않고 안내한다. 대상 변경은 AI 아이콘 우클릭 메뉴에서 설정한다.
# 0.2 화면 수정 — 사용자 사진 2 기준

이번 요청은 실제 실행 화면(사진 1)을 승인 예시(사진 2)의 시각적 구성에 맞추는 작업이다. 사진 1의 기본 WPF/Windows 입력 컨트롤을 그대로 둔 접근을 수정했다.

- 상단: 36px 보라색 아이콘 타일, ‘독에서 이어서 대화’, 작은 서비스 상태, 32px 접기 버튼.
- 서비스 선택/앱 추가와 대화 선택/새 대화 버튼을 각각 34px 두 줄로 정렬했다. 기본 사각 버튼·선택창 대신 라운드 템플릿을 사용한다.
- 498×442 DIP AI 내용 영역, 538 DIP 전체 패널 폭을 기준으로 여백을 정리했다. 빈 대화 영역을 확보하고 입력창을 패널 하단에 고정했다.
- 하단 입력창은 46px, 둥근 테두리와 보라색 위쪽 화살표 버튼이다. 로컬 초안과 미연결 상태는 작은 안내로 표시한다.
- 아이콘은 46px 그라데이션 타일, 흰색 벡터 심벌, 하이라이트·그림자·실행 점으로 구성한다. 탐색기·브라우저·메모·사진 및 독 제어 아이콘을 수정했다. 그 외 앱은 구분을 위해 원래 아이콘을 타일 안에 표시할 수 있다. 가짜 실행 앱을 고정 표시하지 않는다.
- 독 상자에는 기본적으로 배경 채우기와 시스템 배경 흐림을 적용하지 않는다. AI 패널을 열었을 때만 독 전체의 배경을 흰색으로 채우고, 패널을 접으면 다시 투명하게 한다. 아이콘은 선명하게 유지한다.
- 아이콘 호버 확대와 AI 패널의 페이드·가벼운 확대/축소 전환을 사용한다. 패널 높이를 매 프레임 바꾸지 않아 레이아웃 재계산과 창 재배치를 줄인다. 갱신 때 독 제어 버튼을 계속 재생성하던 부분을 제거했다.
- 기존 설정·고정·순서·서비스와 초안은 유지한다. 이미 ChatGPT를 등록했다면 예시의 ‘등록한 앱 없음’ 대신 해당 서비스가 표시된다.

AI의 서비스 이름 등록은 로그인 성공이 아니다. 기존 대화 선택, 새 대화 생성, 전송은 실제 연동 전까지 비활성화한다. 사진 2의 과거 ‘미리보기’ 문구는 실제 프로그램 상태인 ‘실제 대화 연결 전 · 전송 안 됨 · 초안은 이 PC에 저장’으로 교체했다. API 전송/가짜 응답은 추가하지 않았다.

검증: Release XAML/C# 빌드와 기존 클릭 정책 테스트 통과. Windows UI 렌더링·배경 흐림·모션·배율별 실제 화면 비교는 이 Linux 환경에서 수행하지 못했다. 따라서 사진 2와 픽셀 단위 동일함을 확인했다고 주장하지 않는다. 사용자가 실행 확인한 버전은 0.1이며 이번 0.2는 새 Windows 확인이 필요하다.

Windows 확인: 이전 독을 트레이 메뉴로 종료 → 새 버전을 별도 폴더에서 실행 → 보라색 반짝임 아이콘 클릭 → 사진 2와 레이아웃/버튼/입력창/아이콘 비교. 100%와 150% 배율에서 글자 잘림과 패널 크기를 확인하고, 서비스 선택·초안·접기/펼치기·앱 클릭도 확인한다.

참고: [Microsoft DWM backdrop](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type), [DWMWINDOWATTRIBUTE](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute).

다운로드: 기존 전체 버전에서 변경분만 복원하는 업데이트와 기존 작은 버전의 새 파일 복사를 포함한 업데이트 ZIP을 제공한다. 업데이트 스크립트는 Linux PowerShell 7.4에서 전체 복원·작은 버전 복사·기준 파일 불일치 거부·결과 체크섬 오류 거부를 실행 검증했다. 원본 파일 보존과 실패 시 임시 파일 정리도 확인했다. Windows PowerShell 5.1 실행과 Windows 배치 진입점은 미검증이다.

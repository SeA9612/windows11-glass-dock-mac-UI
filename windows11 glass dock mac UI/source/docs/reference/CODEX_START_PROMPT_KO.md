# Codex에서 시작할 요청

첨부한 ZIP을 작업 폴더에 풀고 CODEX_IMPLEMENTATION_BRIEF_KO.md를 먼저 읽어줘. 이 문서가 현재 확정된 요구사항이고, START-HERE.html은 우리가 승인한 수정본 14 미리보기야. 필요하면 대화원문.md와 references 이미지도 함께 확인해줘.

이제 체험용 HTML을 실제 Windows 개인용 프로그램으로 만들어줘. 파일 탐색기·브라우저 내부 UI와 기존 키보드 입력은 그대로 두고, 반투명 독과 실제 앱 감지·창 전환·최소화/복원·미리보기·작업공간·트레이 상태 동기화를 구현해줘. 독은 모든 아이콘이 한 줄로 보이게 하고 Windows 기본 작업 표시줄과 트레이는 유지해줘.

AI는 승인한 독 내부 채팅 및 AI/대화 선택 구성을 사용해줘. 기본은 기존 구독 서비스의 기존 대화를 이어 쓰고 새 대화는 내가 선택할 때만 시작하는 방식이야. API 키나 별도 API 과금으로 바꾸지 마. 먼저 서비스별로 실제 로그인과 기존 대화 조회·동일 대화 전송이 지원되는지 검증하고, 아직 안 되는 부분을 된 것처럼 표시하지 마.

기술 스택은 아직 정하지 않았으니 현재 환경과 Windows 창 제어에 맞게 선택 이유를 짧게 설명하고 구현을 시작해줘. 일반적인 구현 선택마다 멈추지 말고, 최종적으로 실행 방법·검증 결과·남은 제약을 알려줘.
